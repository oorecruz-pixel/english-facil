# English Fácil

Aplicación web de inglés para hispanohablantes, sin IA integrada.

## Probar
Abre `index.html` en un navegador actualizado. No requiere instalación ni API.

## Publicar con GitHub Pages
1. Sube `index.html` a la raíz de este repositorio.
2. Abre Settings → Pages.
3. En Build and deployment, elige Deploy from a branch.
4. Selecciona la rama main y la carpeta /(root), guarda y espera a que aparezca la URL.

## Funciones
Vocabulario traducido con pronunciación aproximada y audio, gramática explicada en español, conversaciones, ejercicios autocorregibles y progreso local.

## Nota
El audio usa las voces disponibles en el navegador/dispositivo. El progreso se guarda localmente en el mismo navegador y no se sincroniza entre dispositivos.
