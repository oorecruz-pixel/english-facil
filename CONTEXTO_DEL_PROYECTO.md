# English Fácil — contexto del proyecto

Objetivo: entrenador personal de inglés para hispanohablantes, adaptable a móviles y computadoras.

Primera versión sin inteligencia artificial, sin API y sin base de datos.
- Vocabulario por temas con traducción y pronunciación aproximada.
- Audio con síntesis de voz del navegador.
- Gramática inicial explicada en español.
- Conversaciones prácticas traducidas.
- Ejercicios autocorregibles con explicación.
- Seguimiento local y exportación de resumen.
- Diseño adaptable y controles accesibles.

Próximas mejoras: ampliar vocabulario y niveles A1/A2, ejercicios de escucha/escritura y, solo si se necesita sincronización, backend y base de datos.
